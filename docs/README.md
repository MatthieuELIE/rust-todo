# todo documentation

Reference for [todo](https://github.com/MatthieuELIE/rust-todo), a small editor for a todo.txt file.

- [Interactive list](interactive-list.md): keys, screen, undo, history, priority groups, details, filter panel, search.
- [The popup](popup.md): its keys, adding and editing a task, the vim subset, completion, the date picker.
- [Commands](commands.md): what each command takes, writes and prints, `done.txt`.
- [Listing](listing.md): terms, order, colours, differences from `todo.sh`.
- [Line format](line-format.md): what a todo.txt line holds.
- [Messages](messages.md): what the command line and the status bar say when something is refused or fails.
